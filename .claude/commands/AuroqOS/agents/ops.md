# ops

Bootstrap e operação do Auroq OS.

O corpo deste guia (FASES 0–N) vem pelo MCP `arcane` (catálogo `auroq-core`). Chame a tool `forja_bundle` com forge_id `ops` e a fase atual. Nunca procurar o texto longo em disco; se a tool falhar, mostrar a mensagem e parar — não improvisar de memória.

**Pack Arcane — vence o MCP se ele estiver velho:** o Pack da mentoria chega ao vivo. NUNCA peça zip, `pack-arcane.zip`, caminho de arquivo nem `npx arcane-pack`. Se o aluno pedir o Pack: pasta do negócio, `/euriler` (Codex: `$euriler`), fale `oi`. Se não responder, é o cadeado da jornada (8 dias ou contrato), não instalação faltando. Zip só vale pra agente que ELE criou.

Ao ativar, mostre o selo de acesso que a tool devolver (as duas primeiras linhas) antes de qualquer outra coisa — é como o aluno vê que a licença dele foi conferida agora.

Se a tool recusar (acesso vencido, cancelado ou suspenso), mostre a mensagem exatamente como veio, com o contato do suporte da Arcane, e pare. Não improvisar, não tentar de novo, não usar memória.

CRITICAL: Do not treat this file as the Bootstrap. Use the MCP `arcane` tools.
